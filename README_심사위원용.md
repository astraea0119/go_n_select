# OFF BEAT TRAVEL

## 심사위원용 MVP 실행 및 검증 안내



### 1. 서비스 개요



OFF BEAT TRAVEL은 여행자가 다음 목적지로 출발하기 직전에

현재 상황을 확인하고, 방문에 문제가 예상되는 경우 대체 목적지를

탐색할 수 있도록 지원하는 상황 대응형 관광서비스 MVP입니다.



본 MVP는 다음 정보를 결합하여 의사결정을 지원합니다.



- 한국관광 데이터랩의 핵심관광지 및 대체추천관광지 데이터

- VISIT JEJU 관광콘텐츠의 관광지 좌표 및 운영정보

- 제주 ITS 교통정보

- 가공·결합된 관광지 및 교통 데이터



본 서비스의 핵심 질문은 다음과 같습니다.



> "지금 여기서 다음 목적지로 출발해도 괜찮은가?"



문제가 예상되는 경우,



> "그렇다면 지금 어디로 가는 것이 더 나은가?"



를 확인할 수 있도록 설계했습니다.

4\. 권장 확인 시나리오



MVP의 핵심 기능은 다음 순서로 확인할 수 있습니다.



핵심 관광지 선택

방문 시점 확인

목적지 운영 가능 여부 확인

현재 교통상황 확인

대체 관광지 확인

대체 관광지의 추천 정보 확인

지도에서 이동거리 및 위치 확인



이를 통해 사전에 계획한 목적지를 그대로 방문하는 것이 적합한지,

또는 현재 상황에서 다른 목적지를 선택하는 것이 적합한지를

확인할 수 있습니다.



5\. 교통정보 확인 시 유의사항



교통정보는 제주 ITS 데이터를 활용합니다.



현재 교통상황과 동일 요일·시간대의 평시 교통상태를 비교하여

관광지 주변 도로의 교통 부담을 판단하도록 구성했습니다.



교통 데이터는 데이터 수집 및 처리 시점에 따라 상태가 달라질 수

있으므로, 서비스 화면에 표시되는 데이터 기준시각과 데이터

신선도를 함께 확인해야 합니다.



※ 교통정보의 실시간성은 실제 API 호출 및 데이터 수집 상태에

따라 달라질 수 있으며, 저장된 최근 데이터가 사용되는 경우에는

해당 데이터의 기준시각을 확인합니다.



6\. 운영정보 확인 시 유의사항



운영정보는 관광콘텐츠 데이터를 기반으로 제공합니다.



운영정보는 실시간 운영정보가 아니며, 원천 데이터에 운영정보가

없거나 확인이 필요한 경우가 존재할 수 있습니다.



따라서 서비스에서 제공하는 운영 가능 여부는 데이터 기준시점의

정보를 기반으로 한 판단이며, 실제 방문 전에는 해당 관광지의

최신 운영 여부를 확인할 필요가 있습니다.



7\. 대체 관광지 추천



대체 관광지는 단순히 거리만을 기준으로 선택하지 않습니다.



가능한 범위에서 다음 정보를 함께 고려하도록 구성했습니다.



운영 가능 여부

관광지 간 공간적 관계

이동 부담

현재 교통상황

관광지 관련 데이터의 존재 여부 및 신뢰도



따라서 추천 결과는 현재 여행 상황에서 선택 가능한 대안을

제시하기 위한 것이며, 모든 상황에서 하나의 최적 목적지를

보장하는 것은 아닙니다.

10\. 본 MVP의 한계



본 자료는 경진대회 제출을 위한 MVP입니다.



실제 관광객을 대상으로 한 시범운영을 수행한 서비스가 아니므로

실제 이용자 수, 관광객 분산효과, 매출 증가, 만족도 향상 등의

실측 성과를 제시하지 않습니다.



따라서 본 MVP에서 확인되는 수치는 서비스 기능 및 데이터

처리·검증 결과를 의미하며, 실제 관광객 행동 변화에 대한

성과 수치로 해석해서는 안 됩니다.



11\. 데이터 품질 및 예외사항



원천 데이터의 관광지명, 좌표, 운영정보 등이 서로 일치하지 않거나

일부 정보가 존재하지 않는 경우가 있습니다.



본 MVP는 이러한 데이터를 임의로 보완하여 100% 매칭시키지 않고,

확인 가능한 데이터 범위 내에서 서비스를 구성하는 것을

원칙으로 합니다.



따라서 일부 관광지에서 대체 관광지 또는 운영정보가

제공되지 않을 수 있습니다.



이는 데이터 품질 및 데이터 결합 과정에서 발생하는 실제

제약사항을 반영한 결과입니다.
